# Regenerable Evidence

Only artifacts produced from committed commands and immutable inputs belong here. Every artifact must identify its generating command, deterministic seed where applicable, tool versions, source commit, dirty-tree state, and UTC timestamp.

An artifact is evidence only for the claim it directly measures. Simulator, fixture, sandbox, local-service, build, and test results must be labeled as such and never stand in for physical-device, provider-production, TestFlight, App Store, real-user, or production evidence.
