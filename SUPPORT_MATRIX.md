# Support Matrix

The repository is **not yet in production**. No device, lens, recording format, or source combination is currently supported or claimed as verified.

An entry may be added only from immutable evidence generated by a committed command and must name all four required dimensions. Absence from this table is unsupported and must never produce a green correction-confidence state.

| Device | OS | Lens | Format | Source | Result | Evidence | Last verified |
|---|---|---|---|---|---|---|---|

## Evidence requirements

Each future row must link to an artifact under `evidence/` that contains:

- device hardware identifier and OS build;
- camera device type and lens position;
- resolution, frame rate, codec, pixel format, and exposure limits;
- source type, nominal/observed modulation or refresh, and test-pattern version;
- algorithm and calibration versions;
- banding reduction, convergence, confidence margin, frame accounting, detail preservation, and thermal outcome as applicable;
- exact regenerating command, immutable input manifest, seed, UTC timestamp, and release commit.
